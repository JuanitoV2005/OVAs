Controlando el Flujo: Decidir y Repetir


 

En el corazón de cada programa de computadora, desde una sencilla aplicación hasta un complejo sistema operativo, se encuentran las estructuras de control de flujo. Estas instrucciones son las que permiten a un programa tomar decisiones, ejecutar tareas repetidamente y adaptar su comportamiento en tiempo de ejecución.

 

En este módulo, nos adentraremos en los dos pilares fundamentales del control de flujo: las estructuras de selección (o condicionales), que dirigen al programa por diferentes caminos según una condición, y las estructuras de repetición (o bucles), que permiten automatizar y repetir acciones hasta alcanzar un objetivo. Comprender estos conceptos es esencial para escribir código que no solo sea funcional, sino también dinámico y eficiente.

Lógica booleana y operadores

La lógica booleana es la base de la toma de decisiones en programación. En Java, se utilizan expresiones booleanas para crear condiciones que evalúan a true o false. Estas expresiones son fundamentales en las estructuras de selección (if-then-else) y de iteración (bucles).

Expresiones Booleanas

Una expresión booleana puede ser una variable de tipo boolean o una comparación entre dos valores. Por ejemplo, x > 5 es una expresión que evalúa a true si el valor de la variable x es mayor que 5, y a false en caso contrario.

Operadores de Relación

Los operadores de relación se utilizan para comparar dos valores.

  • == (igual a)
  • != (no es igual a)
  • < (menor que)
  • > (mayor que)
  • <= (menor o igual que)
  • >= (mayor o igual que)

Operadores Lógicos

Para construir condiciones más complejas, se utilizan los operadores lógicos. Estos operadores combinan expresiones booleanas para producir un único resultado booleano. Los principales son:

  • && (operador AND): La expresión combinada es true solo si ambas expresiones son true.
  • || (operador OR): La expresión combinada es true si al menos una de las expresiones es true.
  • ! (operador NOT): Invierte el valor de la expresión booleana. Si es true la convierte a false, y viceversa.

También es interesante mencionar el concepto de corto circuito (short circuit), que es una optimización en la evaluación de expresiones lógicas. Por ejemplo, en una expresión con &&, si la primera parte es false, la segunda no se evalúa porque el resultado ya se conoce (false). Lo mismo ocurre con || si la primera parte es true.

If simple (decisión básica)

La sentencia if

La sentencia if es la forma más sencilla de una estructura de selección. Se utiliza para ejecutar un bloque de código solo si una condición específica es verdadera (true). Dicha estructura de selección es fundamental para controlar el flujo de un programa.

Estructura básica

La sintaxis de un if simple es la siguiente: 

if (condición) {
        // Código a ejecutar si la condición es verdadera
    }
  • La condición es una expresión booleana que, como vimos, evalúa a true o false. Puede ser una variable booleana, una comparación o una combinación de comparaciones usando operadores lógicos.
  • El bloque de código dentro de las llaves {} se ejecuta solo si la condición es true. Si la condición es false, el programa simplemente salta este bloque y continúa con la siguiente línea de código.

Ejemplo

Considera un programa que verifica si un número es positivo: 

int numero = 10;
  
  if (numero > 0) {
      System.out.println("El número es positivo.");
  }

En este caso, la condición numero > 0 es true (ya que 10 es mayor que 0), por lo que el mensaje "El número es positivo." se imprimirá en la consola.

If–else y cadenas else if

La sentencia if-else

A diferencia del if simple, la sentencia if-else ofrece dos caminos de ejecución. Si la condición es verdadera, se ejecuta un bloque de código; si es falsa, se ejecuta un bloque de código diferente.

Estructura básica

La sintaxis es la siguiente: 

if (condición) {
      // Código si la condición es verdadera (true)
  } else {
      // Código si la condición es falsa (false)
  }

Ejemplo

Para un programa que determina si un número es par o impar: 

int numero = 7;
  
  if (numero % 2 == 0) {
      System.out.println("El número es par.");
  } else {
      System.out.println("El número es impar.");
  }

En este caso, la condición numero % 2 == 0 es falsa, por lo que el programa ejecuta el código dentro del bloque else.

Cadenas else if

Para manejar múltiples condiciones excluyentes, se pueden encadenar sentencias if-else usando else if. Esto permite al programa evaluar varias condiciones en secuencia, y ejecutar el primer bloque de código que corresponda a una condición verdadera.

Estructura básica

La sintaxis es: 

if (condición1) {
      // Código si la condición1 es verdadera
  } else if (condición2) {
      // Código si la condición1 es falsa y la condición2 es verdadera
  } else if (condición3) {
      // Código si la condición1 y 2 son falsas, y la condición3 es verdadera
  } else {
      // Código si ninguna de las condiciones anteriores es verdadera
  }

Ejemplo

Un programa que asigna una calificación a una puntuación: 

int puntuacion = 85;
  
  if (puntuacion >= 90) {
      System.out.println("Calificación: A");
  } else if (puntuacion >= 80) {
      System.out.println("Calificación: B");
  } else if (puntuacion >= 70) {
      System.out.println("Calificación: C");
  } else {
      System.out.println("Calificación: F");
  }

El programa evalúa las condiciones en orden. Como puntuacion >= 90 es falsa, pasa a la siguiente condición. puntuacion >= 80 es verdadera, por lo que imprime "Calificación: B" y el resto de la cadena else if es ignorada.

Switch (selección discreta)

La sentencia switch

La sentencia switch permite que un programa evalúe una expresión y, basándose en su valor, ejecute diferentes bloques de código. Es una forma más limpia y eficiente de manejar múltiples selecciones que las cadenas else if.

Estructura básica

La sintaxis de un switch es la siguiente: 

switch (expresión) {
      case valor1:
          // Código a ejecutar si la expresión coincide con valor1
          break;
      case valor2:
          // Código a ejecutar si la expresión coincide con valor2
          break;
      ...
      default:
          // Código a ejecutar si la expresión no coincide con ningún caso
  }
  • La expresión debe ser de un tipo que admita esta sentencia, como int, char, String o un tipo enumerado.
  • Cada case evalúa si el valor de la expresión es igual al valor especificado.
  • La palabra clave break es crucial, ya que detiene la ejecución dentro del bloque switch. Si se omite, el programa continuará ejecutando el código del siguiente case (fenómeno conocido como "fall-through").
  • La sección default es opcional y se ejecuta si la expresión no coincide con ninguno de los case anteriores. Actúa como el bloque else final en una cadena de if-else if.

Ejemplo

Considera un programa que muestra el nombre de un día de la semana basándose en un número del 1 al 7. 

int dia = 3;
  String nombreDia;
  
  switch (dia) {
      case 1:
          nombreDia = "Lunes";
          break;
      case 2:
          nombreDia = "Martes";
          break;
      case 3:
          nombreDia = "Miércoles";
          break;
      case 4:
          nombreDia = "Jueves";
          break;
      case 5:
          nombreDia = "Viernes";
          break;
      case 6:
          nombreDia = "Sábado";
          break;
      case 7:
          nombreDia = "Domingo";
          break;
      default:
          nombreDia = "Día inválido";
  }
  System.out.println(nombreDia);

En este ejemplo, la expresión dia (con valor 3) coincide con case 3, por lo que el programa asigna "Miércoles" a la variable nombreDia y luego el break lo saca del switch. Si el valor de dia hubiera sido 9, se ejecutaría el bloque default.

While (repetición indefinida, preprueba)

La sentencia while

El bucle while es ideal para situaciones donde no se conoce de antemano el número de veces que se necesita repetir un bloque de código. La repetición continúa mientras la condición sea verdadera.

Estructura básica

La sintaxis del bucle while es la siguiente: 

while (condición) {
      // Código a ejecutar repetidamente
  }
  • La condición es una expresión booleana que se evalúa al principio de cada iteración del bucle.
  • Si la condición es true, el código dentro de las llaves {} se ejecuta. Al finalizar el bloque, el programa regresa y evalúa la condición nuevamente.
  • Si la condición es false desde el principio, el código dentro del bucle nunca se ejecuta.

Ejemplo

Considera un programa que suma los números ingresados por el usuario hasta que ingrese 0. 

import java.util.Scanner;
  
  public class SumaIndefinida {
      public static void main(String[] args) {
          Scanner entrada = new Scanner(System.in);
          int numero;
          int suma = 0;
  
          System.out.println("Ingrese un número (0 para terminar):");
          numero = entrada.nextInt();
  
          while (numero != 0) {
              suma = suma + numero;
              System.out.println("Ingrese un número (0 para terminar):");
              numero = entrada.nextInt();
          }
  
          System.out.println("La suma total es: " + suma);
          entrada.close();
      }
  }

En este ejemplo, la condición del bucle while (numero != 0) se evalúa antes de cada repetición. El bucle se ejecutará mientras el usuario no ingrese un cero. Este tipo de bucle, controlado por un valor especial (0 en este caso) se conoce como "bucle controlado por centinela" (sentinel controlled loop).

Patrones con while: centinela, validación y acumuladores

Patrón del Centinela

El patrón del centinela se utiliza cuando no se sabe de antemano cuántos datos se procesarán. Un valor centinela es un valor especial que se introduce para indicar que el bucle debe terminar. Es un valor que no podría ser un dato válido.

En este patrón, es fundamental usar una "lectura de cebado" o priming read, que es la primera lectura de datos que ocurre fuera del bucle. Esto inicializa la variable de control antes de la primera evaluación de la condición while.

Ejemplo

El programa que suma números hasta que se ingresa un 0 es un ejemplo clásico de un bucle controlado por centinela. Aquí, el 0 es el valor centinela que detiene la ejecución. 

// Lectura de cebado
  System.out.println("Ingrese un número (0 para terminar):");
  numero = entrada.nextInt();
  
  // Bucle controlado por el centinela
  while (numero != 0) {
      // Procesa el dato
      // ...
      // Lectura para la siguiente iteración
      System.out.println("Ingrese un número (0 para terminar):");
      numero = entrada.nextInt();
  }

Patrón del Acumulador

Un acumulador es una variable que se utiliza dentro de un bucle para sumar o "acumular" una serie de valores. Se inicializa antes del bucle (generalmente en 0) y se actualiza en cada iteración.

Ejemplo

En el ejemplo anterior, la variable suma actúa como un acumulador. En cada iteración, se le añade el valor del numero ingresado por el usuario, acumulando el total. 

int suma = 0; // Se inicializa el acumulador
  
  while (numero != 0) {
      suma = suma + numero; // El acumulador se actualiza en cada iteración
      // ...
  }

Patrón de Validación

El patrón de validación usa un bucle while para garantizar que la entrada del usuario cumpla con ciertos criterios antes de que el programa continúe. Este bucle se repetirá indefinidamente hasta que el usuario ingrese un valor válido.

Ejemplo

Supongamos que un programa requiere que el usuario ingrese un número entre 1 y 10. 

import java.util.Scanner;
  
  public class Validacion {
      public static void main(String[] args) {
          Scanner entrada = new Scanner(System.in);
          int numero;
  
          System.out.println("Ingrese un número entre 1 y 10:");
          numero = entrada.nextInt();
  
          // El bucle se repite hasta que el número sea válido
          while (numero < 1 || numero > 10) {
              System.out.println("Número inválido. Por favor, ingrese un número entre 1 y 10:");
              numero = entrada.nextInt();
          }
  
          System.out.println("El número ingresado es: " + numero);
          entrada.close();
      }
  }

En este caso, la condición del bucle while se mantiene verdadera mientras el número sea menor que 1 O mayor que 10, obligando al usuario a reingresar el valor hasta que sea válido.

For (repetición definida, contaje)

La sentencia for

El bucle for es una estructura de control de flujo compacta y fácil de leer que condensa la inicialización, la condición de terminación y la expresión de actualización en una sola línea.

A diferencia del bucle while, que se utiliza para repeticiones indefinidas, el bucle for es ideal para situaciones donde el número de iteraciones se conoce de antemano. Es la estructura más adecuada para el "conteo" o la iteración sobre una secuencia de valores, como por ejemplo, recorrer un arreglo o repetir una acción un número específico de veces.

Estructura básica

La sintaxis del bucle for es la siguiente: 

for (inicialización; condición; actualización) {
            // Código a ejecutar en cada iteración
        }
  • inicialización: Se ejecuta una sola vez al comienzo del bucle. Aquí se declara e inicializa la variable de control (por ejemplo, int i = 0;).
  • condición: Se evalúa antes de cada iteración. El bucle continúa mientras esta condición sea true.
  • actualización: Se ejecuta al final de cada iteración. Aquí se modifica la variable de control (por ejemplo, i++).

Ejemplo

Considera un programa que imprime los números del 1 al 5. 

for (int i = 1; i <= 5; i++) {
            System.out.println(i);
        }

En este ejemplo:

  • inicialización: int i = 1; Se establece la variable de control en 1.
  • condición: i <= 5; El bucle continuará mientras i sea menor o igual a 5.
  • actualización: i++ El valor de i se incrementa en uno al final de cada iteración.

El bucle se ejecutará cinco veces, imprimiendo los números del 1 al 5 en la consola.

For anidados y elección del bucle adecuado

Bucles for Anidados

Un bucle for anidado es un bucle que se encuentra dentro de otro bucle. El bucle interno se ejecuta completamente por cada iteración del bucle externo. Esta estructura es fundamental para trabajar con datos que tienen una naturaleza bidimensional, como matrices o tablas, o para generar patrones.

Estructura y ejemplo

Considera un programa que crea una cuadrícula de asteriscos de 3x3: 

for (int i = 0; i < 3; i++) {       // Bucle externo para las filas
      for (int j = 0; j < 3; j++) {   // Bucle interno para las columnas
          System.out.print("* ");
      }
      System.out.println(); // Salto de línea al terminar la fila
  }

En este ejemplo:

  • El bucle exterior, controlado por la variable i, se ejecuta tres veces (una por cada fila).
  • Por cada iteración del bucle exterior, el bucle interior (controlado por j) se ejecuta tres veces, imprimiendo un asterisco y un espacio.

¿Cuál bucle elegir: for o while?

La elección entre un bucle for y un while depende de si conoces de antemano el número de iteraciones necesarias.

Criterio Bucle for Bucle while
Uso principal Para repeticiones con un número de iteraciones conocido. Para repeticiones que dependen de una condición, donde el número de veces no se conoce.
Tipo de bucle Repetición definida (basado en conteo). Repetición indefinida (basado en una condición de preprueba).
Cuándo usarlo Iterar sobre una matriz o arreglo, imprimir un patrón, o realizar una acción un número fijo de veces. Validar la entrada del usuario, procesar datos de un archivo hasta el final, o cuando se usa un valor centinela.
